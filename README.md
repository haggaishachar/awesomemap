**[→ Explore the live maps](https://awesomemap.dev/)**

Interactive, zoomable treemaps of open-source project ecosystems. Every
rectangle is a project; its size reflects adoption, and its place in the
map is its category. Zoom into a category to see what's inside it, click
any project to see what it does and jump to its GitHub repo or homepage.
Flip any map to **Rising** mode and rectangles resize by star-growth
*velocity* instead — what's accelerating right now, before it's big enough
to show up on the popular view.

Ten domains, ~1,700 projects, and a full daily star-history snapshot
behind every growth number on the site — nothing here is a one-time
scrape.

## Top risers this week

The top 100 projects by 7-day [Rising score](https://awesomemap.dev/methodology/),
recomputed daily. Each entry shows this week's star growth, a bar for its
Rising score relative to #1, and an arrow when its rank moved since the
previous run; 📰 links to the external mention (Hacker News, Reddit,
Product Hunt, or a blog post) behind a spike, when one was found. The full,
filterable [Rising leaderboard](https://awesomemap.dev/rising/) has every
window and every domain.

## Badge for your project's README

Every project on awesomemap gets a README badge that's rebuilt daily with
the site. It always shows the best thing that's true about the project:
a rank this week on its domain's Rising leaderboard, then the best
Rising rank it reached in any archived week (dated, e.g. `#2 Breakout in AI
· Oct 2026`, so a quiet week doesn't reset it), then 7-day star growth, then
a top-10 star rank in its category, then simply which category it's listed
in. It never shows a decline. Open your project's
page, click **Add badge**, and copy the Markdown, or build it by hand:

```markdown
[![awesomemap](https://awesomemap.dev/projects/<owner>/<repo>/badge.svg)](https://awesomemap.dev/projects/<owner>/<repo>/)
```

The same claim is published as a [shields.io endpoint](https://shields.io/badges/endpoint-badge)
at `badge.json` next to `badge.svg`, if you'd rather use one of shields'
styles:

```markdown
![awesomemap](https://img.shields.io/endpoint?url=https%3A%2F%2Fawesomemap.dev%2Fprojects%2F<owner>%2F<repo>%2Fbadge.json&style=for-the-badge)
```
